Put your food photos here (JPG or WebP), then add the file path to the dish's
`image` field in menu-data.js, e.g.  image: "assets/food-images/masala-dosa.jpg"

Tips for fast loading on mobile data:
 - Resize to about 400 x 400 px (square), crop the dish to the centre
 - Save as WebP or JPG at quality 70-80  (aim for under 40 KB each)
 - Free tools: squoosh.app, or any phone gallery "resize" option
 - Use the dish's `id` as the file name so it is easy to match
